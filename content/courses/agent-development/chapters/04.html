第 4 章 · 执行机制

Agent 循环：观察、决策与执行

本章目标：理解循环终止条件，并为 Agent 增加步数、时间和预算保护。

1. 循环的状态

每一步都可以抽象成目标、上下文、模型决策、工具结果和下一状态。状态结构化后，日志和回放会更容易。

2. 终止条件

成功信号、模型明确结束、最大步数、超时和预算耗尽都应该终止。不能只依赖模型“自觉停下来”。

for step in range(max_steps): · action = decide(state) · if action.done: break

3. 失败重试

区分可重试的网络错误、需要修正参数的工具错误和不可重试的权限错误。重试次数应计入成本和观测指标。

4. 练习与总结

为一个搜索问答 Agent 写出五种终止条件。一个好循环应该可暂停、可恢复、可回放。
