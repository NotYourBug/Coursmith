第 7 章 · 复杂任务

任务规划与多 Agent 协作

本章目标：判断什么时候需要拆分任务，以及如何让子任务拥有清晰边界。

1. 先拆边界再拆角色

多 Agent 不是把一个 Prompt 复制几次。拆分应基于不同工具、不同权限或不同验收标准，例如研究、执行和审查。

2. 计划的可执行性

计划步骤必须能映射到工具调用和结果检查。每一步声明输入、输出和失败回滚，避免生成漂亮但无法执行的待办清单。

3. 协作模式

协调者 → 研究者 → 执行者 → 审查者 → 协调者

4. 练习与总结

把“生成一份竞品分析”拆成三个角色，并写出交接格式。角色越多，通信成本越高，先用单 Agent 验证需求。
