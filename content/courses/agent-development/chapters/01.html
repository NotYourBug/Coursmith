Agent 与大模型：能力边界与工作流

本章目标：理解 Agent 与普通聊天机器人的区别，并能画出一个最小工作流。

1. Agent 到底是什么

Agent 不是一个更长的 Prompt，而是一个围绕目标运行的系统。它通常包含模型、上下文、工具、状态和控制循环。模型负责推理与生成，程序负责边界、执行和验证。

2. 四个核心部件

输入定义任务，模型提出下一步，工具执行外部动作，结果再回到上下文中。一个可靠系统必须明确哪些动作由模型建议、哪些动作由程序批准。

3. 最小工作流

用户目标 → 模型决策 → 工具调用 → 结果观察 → 完成或继续

4. 典型误区

把模型输出当作事实、把工具权限全部开放、没有最大步数和超时，都会让原型在真实环境中失控。

5. 练习与总结

请为“读取一份文档并生成摘要”画出输入、模型、工具和验收条件。记住：Agent 的价值不在于会聊天，而在于能在约束下完成任务。
