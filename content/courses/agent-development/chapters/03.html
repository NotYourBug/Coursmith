第 3 章 · 工程接口

工具调用：让 Agent 连接真实世界

本章目标：设计一个有清晰参数、权限和错误返回的工具接口。

1. 工具不是函数名

工具的描述会影响模型选择，参数模式会影响调用正确率，而服务端权限决定了风险上限。工具契约必须像 API 一样被审查。

2. 参数与返回值

参数应尽量少且类型明确。返回值同时包含给模型的摘要和给程序的状态码，避免把大段原始数据无条件塞进上下文。

search_docs(query: str, limit: int) → {"items": [], "next": null}

3. 幂等与超时

查询类工具可以重试，写入类工具要有幂等键。每个调用都应设置超时、记录耗时，并对异常返回可理解的错误。

4. 练习与总结

为“创建工单”设计一个工具，标出哪些字段必须由用户确认。工具越接近真实世界，越需要把权限和确认放在代码层。
