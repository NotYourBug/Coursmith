## 范围

新版部署代码 `m2a-continuation/course_platform` 的学习网站、运营后台和课程制作工作台。旧版 `course_site` 未作为实际部署入口修改。用户确认两类页面均在本次范围内。保留业务路由、CSRF、版本检查、兑换与权限逻辑。

- 纸白与墨绿的统一视觉，中文衬线标题、本地开源字体和品牌标识。
- 首页课程书册视觉、课程分类与介绍、清晰的试学与兑换入口。
- 课程详情的学习成果、章节目录和购买区域；兑换、帮助与阅读样式。
- 分区后台导航、运营待办与审计、登录页、统一表单和可横向滚动的表格。
- 手机上默认折叠导航；无 JavaScript 时保留原生可操作导航。
- 正文编辑与已保存预览分栏，手机纵向排列；阻断状态始终可见，诊断和技术信息分层展开。

## 原有测试

选取模板、管理员认证、商品、订单、课程交付和制作路由，共 286 个原有用例。初轮 284 通过，2 项失败：

2. 订单计数测试依赖旧版精确 HTML，改为读取带标签的真实定义列表数值。

两项修复后的针对性复测及诊断信息测试共 4 项通过。未再次全量运行 286 项，避免重复无关检查。

### 本机限制

宿主 Python 3.12.14 在 Windows 上对同一文件的 lstat/fstat ctime 返回不同含义，原始课程包初始化因此失败。预览与测试工具仅在当前进程使用一致的 st_birthtime_ns，并继续比较身份、大小、mtime 与完整字节快照。线上 `content_inspection.py` 未修改。这些验证不声称已经在实际 Linux 服务器上运行。
