# Coursmith M2A：双模式制作工作台设计规格

日期：2026-10-08（Asia/Shanghai）。状态：本书面规格及实施计划已于 2026-10-09（Asia/Shanghai）获用户明确批准，进入实现阶段。章节默认 10、上限 60；默认单任务 200,000 token 预留额度不自动提高。

代码基线：`da46a21a4b30ecba652efe76c4afe46a962ed816`，已交付的 M1 运营与交付后台。本文描述拟建设的能力，不是当前功能清单，也不授予真实模型调用、生产迁移、部署或发布商品的权限。

## 1. 用户意图与成功标准

经营者希望销售合法的课程及资料，由第三方店铺收款、独立课程站交付；第一版管理员只有经营者本人，保留操作者身份以支持未来多人扩展。品类不限于技术，但首个制作向导是课程，初步内容可使用 Agent 开发，随后再考虑 AI Infra。

本次明确选择内部生产能力优先，而非开放用户收费生成。保留原有“输入题目，其余交给 AI 展开”的习惯，同时增加主题、受众、目标和可选参考资料的精细制作入口。自动化到草稿为止；事实、教学价值、来源授权及商品承诺仍需经营者检查，审核与正式发布属于 M3A。

内容类型字段保留 `course|guide|handbook` 的扩展方向，本期只开放 `course` 制作模板；不能把尚无模板的类型显示为已支持。不同合法品类可以使用课程向导，不强制技术代码练习。

成功是：管理员不依赖日常终端，在网页完成一门课程的需求、大纲、章节生成、编辑和安全预览；失败不误报完成，刷新和进程重启不丢任务，重做不覆盖人工编辑，产生可供 M3A 使用的明确内容快照。

## 2. 范围与分期边界

### 本期包含

- 制作项目库、课程编辑工作台、任务中心三个主页面，沿用 M1 管理员认证与中文后台布局。
- 快速制作、精细制作以及受控模式切换。
- 结构化大纲、稳定章节身份、Markdown 编辑源、显式保存、未保存离开提示与安全预览。
- 粘贴文本、笔记、来源说明；参考资料可选，保留其与生成输入的关联。
- 持久任务、逐章结果、协作取消、手动恢复、失败章节重做、候选结果采用。
- 模型连接的服务端配置、非敏感诊断、明确触发的连接测试、调用用量与未知计费记录。
- 草稿结构检查与不可变交接快照；不生成销售批准记录。
- 离线增量迁移、测试副本恢复验证、安装包资源与运行手册更新。

### 本期不包含

- 正式内容审核、销售发行包、PDF/ZIP 发布、活动版本切换、版本回滚、既有买家升级。
- 站内支付、店铺订单自动采集、收费生成、多租户、多管理员权限页面。
- 任意网址抓取、PDF/Word/OCR 导入、Word 式富文本、图片上传或 AI 绘图、代码在线运行。
- 旧 iframe/脚本课程包转换、批量课程生成、替换旧 CLI/Tkinter/飞书生产入口。
- 自动断言内容正确、授权合法、课程可售，或自动生成已经核实的来源。
- 全面上线运维、CI 平台建设及 M1.1 遗留修复；这些分别立项，不作为 M2A 暗含任务。

M2A 可在测试环境演示完整草稿流程；它完成不等于课程已经能通过新发布流程售卖。生产上线前仍须完成相应运维准备与真实内容验收。

## 3. 路线选择与现有代码约束

选择“独立生产模块，保留旧入口”：延续 FastAPI、Jinja2、SQLite 和 OpenAI 兼容客户端，借鉴现有提示词，但不导入或调用旧生成器的全局流水线。直接网页包装旧脚本成本较低，却继承 CWD、HTML 包装和失败汇总问题；全量重写旧入口或独立 SPA 超出本期需要。

当前 `course_gen_core.py` 包含全局配置、目录切换和脚本驱动的 iframe 包装；新工作台不得通过放松 CSP 或执行旧 HTML 来兼容。`app.py` 当前负责 M1 生命周期组合，新增路由和服务通过组合接入，不继续堆入大块嵌套业务函数。

新增职责边界（目录方向，不是逐文件实施计划）：

| 单元 | 职责 | 主要依赖 |
| --- | --- | --- |
| `production/` | 需求、参考资料、大纲、章节修订、候选采用、快照和渲染 | 事务、内容模型、Markdown 渲染器 |
| `jobs/` | 提交、幂等、领取、租约、步骤结果、取消和恢复 | 数据库、生产服务、注入式模型适配器 |
| 模型适配器 | 明确请求参数、返回文本/用量、统一安全错误 | 服务端配置、OpenAI 兼容客户端 |
| 管理路由与模板 | 认证、CSRF、对象选择、中文表单和任务显示 | 上述服务与 M1 管理安全能力 |
| 应用/CLI 组合 | 注入配置，显式启动独立 worker | 应用工厂、迁移和任务服务 |

模型调用和后台页面不直接改商品政策、发码、销售检查或买家权益。正式 `courses/chapters` 及其既有 ID、文件指纹和进度映射不因创建制作项目而改变。

## 4. 双模式行为契约

### 4.1 快速制作

唯一必填字段是题目。表单同时显示可折叠的默认配置摘要：课程类型、受众、难度、章节数量、模型和执行额度。点击“开始制作草稿”才提交有额度预留的任务，不在输入题目、打开页面或刷新时调用模型。

流程是需求快照 → 自动生成并校验大纲 → 逐章生成 → 草稿检查。AI 推定的受众、先修条件和目标标为“AI 推定，待人工检查”；自动采用的大纲记录为系统展开，不写人工确认人或审核通过。满足结构约束的大纲可继续生成，无需人为逐步确认。

### 4.2 精细制作

题目必填，其余可选：受众、目标、先修条件、难度、章节数、分类及参考资料。先生成大纲，管理员可编辑和排序，明确确认当前大纲修订后才允许批量生成正文。

需求、参考资料或大纲变化使精细模式的大纲确认失效。确认仅批准生成方向，不是事实、来源或商品销售审核。已有章节保留，并标记输入变化后的待检查状态。

### 4.3 切换模式和改大纲

仅无排队/运行修改任务时切换；有任务先取消，待停止或被标记中断后处理。快速转精细保留所有内容，但必须确认当前大纲才能继续批量生成；精细转快速不立即触发调用，下一次明确提交允许自动展开。

每章创建时由服务端赋予稳定 `chapter_id`，排序与身份分离。标题和次序编辑不换 ID。全量重做大纲形成候选，不自动替换已经使用的大纲；采用时管理员确认新旧章节对应关系，不能仅依编号或 AI 猜测匹配。移除的章及正文修订保留为历史，不迁移给另一章。该操作属于本期草稿身份维护，不改既有买家进度。

## 5. 页面与日常操作

| 页面 | 显示与操作 |
| --- | --- |
| 制作项目库 | 题目、模式、最后修改、章节完成情况、正在执行任务、待检查提示；新建、进入、归档 |
| 项目工作台 | 需求/参考资料、大纲、章节编辑、预览、检查结果；生成、确认、保存、重做、比较候选、采用或拒绝 |
| 任务中心/详情 | 任务和执行轮次、当前步骤、成功/失败章、待处理原因、心跳、用量；取消、核对未知调用、确认恢复 |
| 模型配置诊断 | 提供方标签、模型、是否配置密钥、可用限制与连接测试结果；不展示密钥或含认证参数的完整 URL |

M1 导航新增制作项目和任务中心入口，诊断可从任务中心进入。详情页始终区分“生成完成”“结构检查通过”“人工待审核”；前两者不使草稿公开。归档只隐藏日常列表并阻止新生成，历史和用量保留，运行中项目先停止任务。

编辑器是普通 Markdown 文本编辑器，提供有限工具栏、保存按钮和只读渲染预览。不承诺自动保存或跨设备离线编辑。保存携带对象修订；陈旧修订返回冲突，不覆盖服务器版本，页面保留本次输入供复制/比较。JS 提供未保存离开提示；无 JS 时保留原生表单保存、预览和任务刷新，并说明没有离开提醒。正文不存入 localStorage。

基础任务页通过手动刷新读取数据库事实；可选同站脚本轮询最多每 10 秒一次，不能触发模型调用。使用轮询时 CSP 仅增加同站 `connect-src 'self'`，不新增外部脚本、iframe 或任意连接许可。

## 6. 数据与修订

M2A 在最新 schema5 后新增不可变增量迁移，设计版本为 schema6；实施前复核是否已有后继迁移，不改写 v001–v005。已有库须离线备份并显式迁移；应用和 worker 不在启动时自动升级旧库，导入模块不迁移或启动任务。

本期小规模文本编辑源以 SQLite 为事实来源，减少 DB 与草稿文件的双写问题。Markdown、参考文本和生成候选是私有正文数据，不写普通日志。持久关系至少分离：

| 数据对象 | 必须保存的信息 |
| --- | --- |
| 制作项目与需求修订 | ID、模式、类型、分类、创建人、状态、题目、需求字段、当前修订 |
| 参考资料修订 | 项目、资料 ID、正文、来源说明、来源状态、修订及内容哈希 |
| 大纲修订与确认 | 有序章节 ID/标题/目标、输入快照哈希、生成或人工来源、确认对象与时间 |
| 章节与正文修订 | 稳定 ID、当前修订指针、Markdown、生成输入、编辑者、候选来源、待检查原因 |
| 任务、执行轮次与步骤 | 类型、提交者、幂等摘要、输入快照、状态、取消请求、租约/token、每章结果 |
| 模型调用与额度预留 | 请求/模型/提示词版本、状态、用量或未知、预留、核对记录 |
| 交接快照与检查结果 | 项目修订、各引用修订/哈希、检查发现、快照哈希和创建人 |

固定内容字段可以用经校验 JSON 保存，但 ID、修订、状态、唯一约束、关联和额度不能全部塞进一个不透明 JSON。时间存 UTC，显示沿用 Asia/Shanghai。引用历史不硬删除。

默认使用数据库源正文，不新增公开文件挂载。必要的派生产物只写服务端配置的私有工作根，必须与 `COURSE_CONTENT_ROOT`、静态目录和备份根分离；路径由服务端对象 ID 派生、拒绝越界和符号链接，不接受管理员提交的任意文件路径。派生产物不是事实来源，缺失可从源快照重建；未知孤立文件不自动清理。

## 7. 任务生命周期与并发

本期固定任务类型为 `course_draft_generate`（快速模式）、`outline_generate`、`chapters_generate`、`chapter_regenerate`、`draft_validate`、`connection_test`。不注册 publish、PDF、ZIP、backup 或任意 shell 任务。

基本状态是 `queued → running → succeeded|failed|cancelled|interrupted`。阻塞原因作为明确代码保存，例如额度不足、未知调用待核对、输入冲突、模型输出无效。部分成功但尚有失败/未完成的生成任务不能是 succeeded。任务步骤和课程草稿状态分离，任务完成不等于项目已审核。

已知额度不足、未知响应或输出失败使当前任务以 failed 结束，并保存相应原因和成功步骤；worker 失联才是 interrupted。归档项目不能提交新任务。所有终态不可由“恢复”改回 running，恢复创建关联的新任务。

- 单主机、一个 Web 和一个独立 worker，第一版 worker 同时执行一个任务、一个模型请求；本期不使用 Web 内存线程队列或 Redis。
- 提交记录任务及冻结输入，短事务锁定项目，跨标签重复点击依幂等键返回同一任务；同键异载荷冲突。每项目最多一个 queued/running 修改任务。
- worker 通过短事务领取和更新，网络调用不持有写锁。每 10 秒独立更新心跳，租约 60 秒；心跳不被最长 120 秒模型调用阻塞。
- 租约失效立即禁止该执行 token 更新当前正文。连续 120 秒无心跳后标 interrupted，并释放项目修改槽位；此前不能由另一 worker 自动接管。
- 心跳失效检查由 worker 周期维护执行，也可由管理员明确“检查中断状态”触发；公共 GET 不修改任务。维护不执行恢复调用。
- 每执行轮次有新 attempt token，写正文指针、活动候选及步骤状态均检查其有效性；旧轮次不再有修改当前内容的权限。
- 外部调用可能已经发出而未保存响应；不承诺绝对恰好一次。过期 token 的账务/响应回收只可附到原调用和原轮次，作为隔离历史而不是可直接采用的活动候选，不能恢复过期修改权。

### 7.1 生成结果如何落地

首次空白章生成可在 token、输入修订、当前正文仍为空均匹配时创建并采用正文修订。已有正文的生成一律作为候选，人工编辑不被覆盖。手工保存与生成结果提交使用同一项目事务/修订规则；token 仍有效但正文修订冲突时保留候选并提示冲突，token 过期时仅按上节规则归档响应。

允许编辑已完成章，但不允许在生成期间改需求、参考资料、大纲或当前正在生成章。章节重做显式锁定对应章；编辑和候选采用若冲突返回可恢复的中文提示，不吞掉本次输入。

### 7.2 取消与恢复

取消 queued 任务立即终结且不调用模型；取消 running 任务写取消请求，worker 不再启动下一请求或自动采用新结果。已发请求可完成并计费，其响应只能作为私有候选/调用记录保留。若 worker 消失，以租约和中断维护阻止后续采用；绝不伪造立即停费。

失败、中断或取消后，恢复页列出已成功结果、待生成章、输入是否变化、未知调用及新预留额度。管理员确认后创建新的关联恢复任务和执行 token，不擦除原任务历史，不自动重做成功章节。快照输入已变则生成新的制作任务，不能借“恢复”跳过精细模式确认；明确选择的逐章重做仍采用候选规则。

## 8. 模型连接、用量与输入限制

沿用服务端 `COURSE_BASE_URL`、`DEEPSEEK_API_KEY`，新增独立模型名配置 `COURSE_MODEL`（初始默认 deepseek-chat）。Web 与 worker 用相同的注入配置，不 import 旧全局初始化；页面不允许写入 API Key、任意端点或 shell。模型更换和密钥轮换属于维护配置，本期不做网页密钥管理。

任务冻结非敏感的提供方/模型标识、上下文限额、输出上限和提示词版本；配置指纹不含密钥。worker 执行前发现端点或模型等执行条件变化时停止并要求新任务，不静默改用另一模型；同执行条件的密钥轮换不要求在任务中存旧密钥。模型上下文限额由维护配置明确给定，未知则拒绝执行，不根据模型名字猜测。

连接测试是有 CSRF 的明确提交，通过同一任务/用量机制进行一次小输出请求；界面提示可能计费，不在打开诊断页时发请求。测试和验收默认使用假模型；真实请求需经营者提供配置并明确授权，不能以测试为名隐式消耗额度。

关闭 SDK 隐式重试。单次调用总截止时间 120 秒（包括流式场景），认证/结构错误不自动重试。只有适配器可证明未接受请求的短暂失败允许最多两次重试，间隔 2 秒、8 秒；普通 5xx、超时、连接断开或不明返回不能仅凭状态码认定未计费。输出无效先保留安全诊断，修复/重做须明确提交。

每调用记录提供方标签、模型、请求 ID（若有）、输入快照与提示词版本、开始/结束、token usage 或 unknown、错误代码。无单价时金额显示“未配置”；有带日期和币种的人工单价时只是估算，不表示供应商账单或利润。

每个生成任务有执行预留上限，提交前按各计划逻辑请求的保守输入估算与输出上限预留，不将互斥的首次调用与两次重试额度同时重复占用。每个实际尝试都有独立调用记录和预留，实际发请求前再次检查剩余额度和提供方上下文上限。只有适配器明确证明供应商未接受请求的失败，才可按 rejected、已知零用量结算并释放该次预留；随后先独立预留重试，再发送新请求。未知或接受情况不明的调用不释放预留，也不自动重试。本段重试预留解释于 2026-10-10（Asia/Shanghai）获用户明确选择；所有技术数值保持不变。模型输出量通过支持的请求参数限制；不能可靠确定约束时拒绝提交。未知调用保留预留并阻止该任务继续花费，管理员记录已用量或确认接受再次调用风险后才可创建新的恢复任务；原 unknown 与核对历史不改成零费用。

下列是书面规格拟定的技术默认值，须随本规格一起审批；不是商业服务承诺或精确账单封顶：

| 项目 | 默认/上限 |
| --- | --- |
| 课程章数 | 默认 10，范围 1–60 |
| 题目 | 1–200 Unicode 字符；去除空白后不得为空 |
| 单项需求文本 | 最多 2,000 字符；全部需求文本最多 10,000 字符 |
| 参考资料 | 最多 10 条，正文合计最多 20,000 字符；每条来源说明最多 1,000 字符 |
| 单章源正文或候选 | UTF-8 最多 200 KiB；请求体最多 2 MiB |
| 大纲模型输出 | 最多 4,000 输出 token |
| 章节模型输出 | 每调用最多 4,000 输出 token |
| 连接测试输出 | 最多 32 输出 token，一次请求，无自动重试 |
| 单任务 token 预留上限 | 默认 200,000，可由服务端维护配置调整；不合额度时停止，不截断参考资料 |

输入估算优先使用匹配提供方的计数规则；缺少可靠计数时以完整请求正文的 UTF-8 字节数加 2,048 token 协议余量作为保守估算，并标注估算。实际 usage 可能与估算不同；提供方额外推理/缓存计费规则无法可靠限制时不宣称精确 token 或金额封顶。超出章数、正文、上下文或预留上限时返回字段级错误或额度原因，不能静默删减、截断生成正文或继续无限生成。

各输入上限不表示任意组合都能在默认额度和模型上下文内运行；页面须在提交前说明组合超限原因。快速任务的大纲尚未确定时先保守预留计划章数；大纲产生后按实际请求输入重算，超限即停止，不先生成再补额度。

## 9. 参考资料与安全渲染

每条参考资料保留原文本、来源说明、来源状态与输入修订。没有来源说明时为“未提供来源”；AI 提出的链接/书目为“待核查”，不自动认定真实、授权或支撑对应论述。人工填写核查说明也不是系统的法律认证。正文不声称凭章节结构检查完成事实审查。

参考资料和模型输出都是不可信输入。提示词区分经营者指令和资料文本，但不把提示词隔离当作安全保证；模型没有工具、网页抓取、任意文件读写或执行代码能力。请求正文只含冻结的生产输入（需求、参考资料、适用的大纲/章节源）及受控模板，不含订单、买家记录、管理员密码或模型密钥；模型密钥仅用于服务端认证。提交界面提醒不要粘贴商业秘密、个人信息和凭证。

Markdown 渲染使用关闭原生 HTML 的配置，并经过标签/属性/URL 白名单清洗；具体依赖拟采用 markdown-it-py 与 nh3，实施时锁定并验证选定版本，不在规格阶段安装。代码示例里的 HTML 作为文本展示，不执行 script、iframe、SVG、事件属性、任意样式或表单。

首版无素材上传；模型给出的图片不发起网络请求，转为占位/待补素材提示。正文链接仅允许经校验 HTTP(S) 协议，标为外部资料，浏览器打开时使用安全关系属性；javascript/data/file、认证 URL、异常控制字符和根外路径拒绝。预览不抓取链接、不下载外部资源。

原始模型响应仅作为经过大小限制的私有候选文本，不能内嵌为可信 HTML。预览由后台渲染受控片段，不依赖放宽 iframe/CSP。所有制作、候选、参考资料、快照及任务详情要求当前管理员授权、对象访问检查和 no-store；买家 Cookie 不授予任何制作权限。

写操作沿用规范同站 Origin/CSRF 和管理员认证，包括测试连接、生成、保存、确认、取消、恢复及采用候选。幂等键不等于授权。所有普通日志、审计和错误响应只保存允许的对象 ID、动作、修订、状态、错误代码、请求 ID与用量，不保存题目、正文、资料、提示词、凭证、Authorization 或 SDK 异常原文。缺失/认证失败不回显密钥片段。

## 10. 草稿检查与 M3A 交接

检查区分阻断项和人工检查提醒：大纲结构/身份唯一性、章节与当前大纲对应、正文缺失/超限、安全渲染、输入变化后的待处理候选；事实、深度、案例可复现、来源授权及销售承诺始终是人工待检查项。生成完整不解除人工待检查。

课程模板要求学习目标、讲解、案例、练习与总结；缺项属于结构阻断项。案例/练习按品类组织，不要求非技术课程提供代码；有对应标题不代表内容正确、足够深入或具有教学价值。

“生成交接快照”只允许无修改任务、所有活动章有正文、结构阻断项解决且已明确处理输入变化/候选选择后执行。精细模式另要求当前需求/参考资料/大纲修订已确认；快速模式不伪造人工大纲确认。显式确认待检查变更只是承认复核需求，不冒充正式内容审核。

快照是当前需求、大纲、章节修订、参考资料、来源状态、渲染与提示词版本的不可变引用集合，以规范 UTF-8 序列化计算 SHA-256。后续编辑创建新修订，旧快照不变化。检查结果绑定相同快照，不依赖当时仍在变化的 current 指针。

M3A 将读取该快照执行正式审核、统一 HTML/PDF/ZIP 编译、发布与版本政策。M2A 不写入当前 M1 的已发布课程文件树，不让草稿经公开目录被扫描，不建立销售审批或改变已购权益。稳定草稿章节 ID 仅是后续映射输入，M3A 仍需独立设计历史章节兼容与买家进度迁移。

## 11. 异常、迁移与运行

业务错误以中文说明、下一步和关联 ID 呈现；字段错误标对字段，冲突保留本次编辑文本，其他错误不回显正文/配置。磁盘不足、数据库忙、模型不可用、输出无效、心跳中断和额度不足分别记录代码，不用统一“成功”或无限自动重试掩盖。

首次安装/迁移、服务配置和独立 worker 启动仍属维护操作；经营者日常制作只需网页。Web 重启不能启动隐藏 worker，worker 重启不能自动重发失联调用。系统诊断显示 worker 心跳及最近维护时间，过期状态明确为异常，不从页面存在推定运行正常。

迁移验证使用独立数据库副本：保留 M1 商品、订单、码、权益、审核快照、期限及进度；旧程序只能回滚到旧兼容备份，不能读取升级库。M2A 新源正文在数据库中，备份必须包含它及引用的私有派生产物清单；恢复时核对 revision/hash，不能只恢复任务元数据。真实生产备份、升级、切换仍须另行授权。
